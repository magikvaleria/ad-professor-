# Rosanna Rojas — Sitio web 🌻

Un sitio web personal con estilo de los años setenta para la tía más cool, Rosanna Rojas. En español.

## Cómo verlo
Es un sitio estático (HTML + CSS, sin build). Abre `index.html` en cualquier navegador,
o sírvelo localmente:

```bash
cd rosanna-rojas
python3 -m http.server 8080
# luego abre http://localhost:8080
```

## Archivos
- `index.html` — el contenido del sitio
- `styles.css` — el estilo setentero (colores cálidos, tipografía retro, tocadiscos giratorio)

## Personalizar
- Cambia los textos directamente en `index.html`.
- En la sección **Galería**, reemplaza los marcos `.polaroid__photo` con imágenes reales
  (`<img src="...">`) cuando tengas fotos.
