## How to add a quote

1. Open the file for the book you're reading (or create a new one).
2. Add the quote under a `##` chapter or page heading, as a `>` blockquote.
3. Optionally add a line or two of your own thoughts below it.

To start a new book, copy `neville-goddard/your-faith-is-your-fortune.md`
as a template and rename it.
